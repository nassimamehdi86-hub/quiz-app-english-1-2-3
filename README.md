# English Vocabulary Sequences

تطبيق ويب (PWA) للتدرب على مصطلحات وعبارات اللغة الإنجليزية، يضم ثلاثة مقاطع (Sequences)، كل واحد فيه درس صوتي واختبارات تفاعلية.

## الملفات
- `index.html` — التطبيق كاملاً (شاشة اختيار المقطع + المقاطع 1/2/3)
- `manifest.json` — بيانات تثبيت التطبيق (PWA)
- `sw.js` — Service Worker للعمل بدون إنترنت
- `icon-192.png`, `icon-512.png` — أيقونة التطبيق (علم بريطانيا 🇬🇧)

## النشر على GitHub Pages
1. أنشئ مستودع (repository) جديد على GitHub وارفع هذه الملفات الخمسة إلى جذر المستودع (root).
2. من إعدادات المستودع: **Settings → Pages**.
3. تحت **Source** اختر الفرع `main` (أو `master`) والمجلد `/ (root)`، ثم اضغط **Save**.
4. بعد دقيقة أو دقيقتين، سيصبح التطبيق متاحاً على رابط مثل:
   `https://USERNAME.github.io/REPO-NAME/`
5. افتح الرابط من الهاتف واضغط زر **"📲 تثبيت التطبيق"** الظاهر أسفل الشاشة لتثبيته كتطبيق مستقل.

## ملاحظة
لا حاجة لأي إعداد إضافي أو خادم (server) — كل الملفات ثابتة (static) وتعمل مباشرة على GitHub Pages.
